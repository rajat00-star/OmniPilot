# Requirement-to-evidence checklist

Track (from the team's submission deck): **Build an AI-Native Browser with an Autonomous Multimodal Companion Using AdaL**. No official organiser brief was found in the repository or on the developer Mac (searched 2026-10-28, see `docs/evidence/finale-audit-2026-10-28/problem-statement.txt`). The 16 items below are the checklist the team set for the Grand Finale, and they include the 9 requirements in [VALIDATION.md](VALIDATION.md).

Status key:
- **Verified**: implemented and verified. It was executed and passed, and the evidence is linked.
- **Implemented, not fully verified**: the code exists and has automated tests, but a stated part has not been exercised for real.
- **Incomplete**: missing in whole or in part.
- **Blocked**: needs something outside this repository, such as a person, a credential or an account.

Evidence types:
- *unit*: code-level tests.
- *local E2E*: real Chromium against fictional sites served on this machine.
- *live*: real public websites.
- *stand-in API*: a local fake of the Claude API. No real call is made.

Test counts are from the run recorded in [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md).
