Instructions for Claude
Get it done
Quick answers or long tasks — Ask something quick, or hand off a long, complex task that keeps working after you close your laptop.
Parallel tasks — Run several tasks with Claude at the same time.
Frontier intelligence — Access to Claude’s latest models for reasoning, coding, and writing.
Scheduled tasks — Set up work Claude runs again on a schedule you choose.
Voice — Talk to Claude instead of typing.
Finished, editable work — Get editable, polished files, ready for your review.
Artifacts — Shareable, on-brand designs, slides, and documents. Edit yourself or tell Claude what to change.
Interactive visuals — Build charts, diagrams, and interactive visuals right in the conversation.
Access tools
The web — Search the web for current information.
Connectors — Connect the apps you already use, including interactive MCP apps.
Files and folders — Work with the files and folders already on your desktop.
Browser use — Browse and act on the web through Claude in Chrome and the built-in browser.
Computer use — See and use your screen (beta).
Make it yours
Skills — Teach Claude new skills, record them, and share with your team.
Plugins — Add plugins from the marketplace to extend what Claude can do.
Custom connectors and MCPs — Build your own connectors and MCPs, including local desktop extensions.
Stay in control
Permissions control — Turn on permissions settings so Claude shows its plan and waits for your approval. Redirect or stop anytime.
Access controls — Claude is designed to work in the folders and tools you allow, and by default asks before permanently deleting files.
Administrative tools for Team and Enterprise — Admins set access by team, manage spend limits, and control tool permissions by department. Activity streams to your SIEM through OpenTelemetry.
Cloud providers — Use a Claude account, or your own cloud provider: Access Claude through Amazon Bedrock, Gemini Enterprise Agent Platform, or Microsoft Foundry.
Work where you want
Desktop, web, mobile — Use Claude on the web, on desktop, or on your phone.
Claude in Chrome — Claude lives inside Chrome, ready wherever you browse.
Claude for Microsoft 365 — Claude lives inside the Microsoft 365 apps you already use.
Claude Tag — Work with Claude directly in Slack. Tag Claude and it gets things done. In beta for Team and Enterprise plans.
Don’t start over
Memory — Remember context from past conversations.
Projects — Keep context, instructions, and files organized by project.
Instructions for Claude — Set preferences that apply across every conversation.

What is Claude?

Claude is more than an AI assistant: it’s a helpful, intuitive, and powerful collaborator you can put to work on real tasks, not just questions. Point it to files and tools you want it to access, give it a goal or an outcome you want in plain language, and it gets to work. It can produce real files like documents, spreadsheets, and slides that you review, edit, and sign off on.
