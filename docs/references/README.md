# OmniPilot visual references

These are the two reference videos supplied for the OmniPilot redesign.

Please inspect the videos for visual direction only: 3D environment, cinematic transitions, glowing elements, composition, motion pacing, and sound-design inspiration. Create an original OmniPilot experience rather than copying the reference sites/assets.

Keep these files in `docs/references/` locally. They are reference material and do not need to be committed or pushed to GitHub unless the team explicitly wants them in the repository. Check repository size and licensing before committing large media files.
